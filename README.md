# Najm Store

واجهة متجر حديثة باللغة العربية لعرض أبرز أقسام وعروض متجر نجم ستور على منصة سلة.

## نظرة عامة
- صفحة رئيسية متجاوبة بالكامل مع تصميم مستوحى من الهوية البصرية للمتجر.
- إبراز المميزات الرئيسية للمتجر والأقسام والمنتجات الأكثر مبيعًا.
- قسم آراء العملاء ودعوة لاتخاذ إجراء للتواصل مع فريق المتجر.

## البدء
افتح الملف `index.html` في أي متصفح حديث للاستعراض أو التطوير.

## التخصيص
- حدِّث أسماء المنتجات والأسعار والعروض حسب التحديثات الفعلية في المتجر.
- استبدل صور العملاء والروابط بالبيانات الحقيقية من لوحة تحكم سلة.
- أضف تكاملات الدفع أو روابط الطلب المباشر حسب الحاجة.

## الترخيص
تم إنشاء هذا القالب لأغراض العرض ويمكن تعديله بحرية ضمن نطاق فريق نجم ستور.
